# Փորձնական վճարումներ (Stripe Sandbox)

Այս մասը նախատեսված է միայն նախագծի ցուցադրման համար։ Այն ընդունում է միայն
`sk_test_` բանալի և `cs_test_` վճարման session։ `sk_live_` բանալին մերժվում է։
Իրական գումար չի փոխանցվում։ Subscription, վճարովի ծառայության ակտիվացում կամ
վաճառողին գումարի փոխանցում չկա։

## Միացնել

1. Ստեղծիր Stripe-ի անվճար հաշիվ և բացիր **Sandbox** միջավայրը։
   [Պաշտոնական ուղեցույց](https://docs.stripe.com/sandboxes)։
2. Sandbox-ի API keys բաժնից վերցրու **secret key**-ը՝ `sk_test_...`։
   Մի ակտիվացրու իրական վճարումները։ Frontend-ին բանալի պետք չէ։
3. `backend/.env` ֆայլում ավելացրու այս տողը՝ քո test բանալիով.

   ```env
   STRIPE_TEST_SECRET_KEY=sk_test_...
   ```

   Բանալին պահիր միայն `.env`-ում։ Կոդի մեջ կամ Git-ում այն մի տեղադրիր։
   `CLIENT_URL`-ը պետք է համապատասխանի frontend-ի հասցեին
   (տեղային աշխատանքի համար՝ `http://localhost:5173`)։
4. Backend-ի պանակից գործարկիր.

   ```bash
   npm install
   npm run db:migrate:orders
   npm run dev
   ```

   Migration-ը միայն ավելացնում է `orders` աղյուսակը և կարելի է կրկնել։
   Նոր բազայում `DB_SYNC=true`-ով աղյուսակը ստեղծվում է նաև server-ի մեկնարկին։
   Գոյություն ունեցող `users` և `listings` աղյուսակները պետք է արդեն ստեղծված լինեն։
5. Frontend-ի պանակից գործարկիր `npm run dev`։

Եթե բանալին բացակայում է կամ live բանալի է գրված, հայտարարության էջը ցույց կտա,
որ test վճարումները դեռ հասանելի չեն։ Մնացած նախագիծը շարունակում է աշխատել։

## Փորձել

1. Մուտք գործիր և բացիր **ուրիշ օգտատիրոջ ակտիվ հայտարարությունը**։ Գինը պետք է
   լինի $0.50–$999,999.99։ Գները USD են՝ ինչպես նախագծի գործող էջերում։
2. Սեղմիր **Buy (test)**։ Բացվում է Stripe-ի պատրաստի test վճարման էջը։
3. Օգտագործիր `4242 4242 4242 4242`, ապագա ամսաթիվ և ցանկացած 3-նիշ CVC։
   Օգտագործիր միայն Stripe-ի թեստային քարտերը։
4. Վճարումից հետո վերադարձիր կայք։ Backend-ը Stripe-ից ստուգում է վճարումը,
   հետո պահպանում պատվերը։ Այն երևում է **My purchases** բաժնում։
5. Փորձիր նաև մերժվող քարտը՝ `4000 0000 0000 0002`, և Checkout-ի հետ գնալու կոճակը։
   Մերժված կամ չեղարկված վճարումը գնում չի ստեղծում։

Սա demo գնում է. այն չի փոխում հայտարարության կարգավիճակը, որպեսզի նույն
հայտարարությամբ հնարավոր լինի կրկին ցուցադրել փորձնական վճարումը։

## Ինչպես կարդալ կոդը

Հոսքը նույնն է, ինչ նախագծի մնացած մասերում.

1. `frontend/src/components/pages/payment/BuyListing.tsx` — «Գնել» կոճակն է։
2. `frontend/store/api/paymentsApi.ts` — RTK Query-ով դիմում է backend-ին։
3. `backend/src/routes/payment.routes.js` — պահանջում է մուտք և ստուգում մուտքային տվյալները։
4. `backend/src/controllers/payment.controller.js` — կանչում է service-ը։
5. `backend/src/services/payment.service.js` — բազայից վերցնում է գինը,
   ստեղծում Stripe Checkout-ը և ստուգում վճարման արդյունքը։
6. `backend/src/models/Order.js` — Sequelize-ով պահպանում է հաստատված test գնումը։
7. `PaymentSuccess.tsx` — ցույց է տալիս արդյունքը։ `Purchases.tsx` — գնումների ցանկը։

Նոր գրադարանը միայն backend-ի `stripe` փաթեթն է։ Frontend-ում շարունակում ենք
օգտագործել նույն React hooks-ը, React Router-ը, RTK Query-ն ու Tailwind-ը։
Քարտի տվյալները մշակվում են Stripe-ի էջում և մեր բազայում չեն պահվում։

`amount`-ը ցենտերով է. օրինակ `1250` նշանակում է `$12.50`։ Գինը միշտ վերցվում է
բազայից։ Frontend-ից ուղարկված ուրիշ գին կամ buyer ID չի օգտագործվում։
`findOrCreate`-ը և unique `stripeSessionId`-ը թույլ չեն տալիս էջը թարմացնելիս
նույն վճարման համար կրկնակի պատվեր ստեղծել։

## Սահմանափակում

Այս պարզ demo տարբերակում հաստատումն արվում է Stripe-ից կայք վերադառնալիս։
Եթե հաջող վճարումից հետո փակես էջը՝ առանց կայք վերադառնալու, տեղային պատվերը չի
պահպանվի մինչև նույն success հղումով վերադարձը։ Իրական վաճառքի համար Stripe-ը
պահանջում է նաև webhook-ով հաստատում. այս նախագիծը իրական վաճառքի համար չէ։
[Stripe-ի բացատրությունը](https://docs.stripe.com/checkout/fulfillment)։

## API

Բոլոր endpoint-ները պահանջում են նույն Bearer access token-ը, ինչ մյուս account բաժինները։

- `GET /api/payments/config` — test վճարումը միացվա՞ծ է։ Բանալին չի վերադարձնում։
- `POST /api/payments/checkout` — `{ "listingId": 5 }` → `{ success, data: { url } }`։
- `POST /api/payments/confirm` — `{ "sessionId": "cs_test_..." }` → `{ success, data: order }`։
- `GET /api/payments/mine?page=1` — միայն իմ գնումները, էջում՝ 12 հատ։

Ստուգելու համար backend-ում և frontend-ում գործարկիր `npm run test:payments`։
Թեստերը չեն դիմում Stripe-ին և գումար չեն փոխանցում։
